Territory Run · Visual system · v1

Claim the map, one loop at a time.

The locked visual language for Territory Run — a GPS running game where Singapore is split into four regional teams and runners capture land by closing loops. Bold and playful: high-contrast team colors, confident type, game-y celebration. Light mode is primary; dark is reserved for the active run. Every screen we build next inherits from this sheet.
